## 💻 Development

### Prerequisites

- Node.js and npm/yarn installed
- Basic knowledge of HTML, CSS, and JavaScript

### Getting Started

1. **Clone the repository**

   ```bash
   git clone https://github.com/darshan09200/darshan09200.github.io.git
   cd darshan09200.github.io
   ```

2. **Install dependencies**

   ```bash
   yarn install
   # or
   npm install
   ```

3. **Start development**

   ```bash
   yarn dev
   # or
   npm run dev
   ```

   This will watch for changes in `css/input.css` and automatically rebuild the CSS.

4. **Open in browser**

   Open `index.html` in your browser or use a local server like Live Server.

### Available Scripts

- `yarn build:css` - Build and minify CSS
- `yarn dev` - Watch for CSS changes during development
- `yarn clean` - Remove compiled CSS file
- `yarn postinstall` - Automatically build CSS after installing dependencies
